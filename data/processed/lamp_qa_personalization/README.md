# LaMP-QA Personalization

Processed LaMP-QA subset for personalized long-form question answering.

## Source Links

- GitHub: https://github.com/LaMP-Benchmark/LaMP-QA
- Hugging Face: https://huggingface.co/datasets/alireza7/LaMP-QA
- Paper: https://arxiv.org/abs/2506.00137

## Expected Files

- `profiles.jsonl`
- `questions.jsonl`
- `retrieved_contexts.jsonl`
- `answers.jsonl`

## Role

Personalization extension, separate from the primary EPBench retrieval evaluation.

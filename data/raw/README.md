# Raw Data

Store unmodified source dataset files here.

## Sources

- `lmeb/epbench/`: EPBench source files from LMEB.
- `lamp_qa/`: LaMP-QA source files.

Record download date, source URL, version, and license in each dataset folder before processing.

## Download Scope

- `lmeb/epbench/`: full `mteb/EPBench` Hugging Face dataset repository.
- `lamp_qa/`: LaMP-QA Hugging Face dataset card plus validation JSON files for all three top-level categories.

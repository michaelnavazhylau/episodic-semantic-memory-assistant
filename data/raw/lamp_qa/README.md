# Raw LaMP-QA

LaMP-QA source files for the personalization extension.

## Role

Personalized long-form question-answering extension.

## Download Scope

- Download date: 2026-07-18.
- Downloaded files:
  - Hugging Face dataset card copied to `HF_README.md`.
  - `data/Art_and_Entertainment/validation/validation.json`.
  - `data/Lifestyle_and_Personal_Development/validation/validation.json`.
  - `data/Society_and_Culture/validation/validation.json`.
- Full train/test splits were not downloaded because the full dataset is multi-GB and the project plan only requires a validation sample.
